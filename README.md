# أ. أحمد زين العابدين — Mr. Ahmed Zain Al-Abideen

ألعاب تفاعلية لمادة الرياضيات — الصف السابع.

- `index.html` : الصفحة الرئيسية (الدروس)
- `game.html?l=1` : الدرس الأول — كتابة المعادلات وحلها
- `game.html?l=2` : الدرس الثانى — استنتاج واستخدام الصيغ 
- `game.html?l=3` : الدرس الثالث — فك الأقواس
- `game.html?l=4` : الدرس الرابع — ترتيب الأعداد العشرية والكسور العشرية (لعبة «من سيربح المليون؟» بدل الفقاعات)
- `data/` : أسئلة كل درس — الألعاب فى كل الدروس: تسجيل الأهداف، شد الحبل، صح أم خطأ، التوصيل، الفقاعات، التنشين (6 × 15 سؤالًا، بدون وقت محدد)
- `assets/` : التصميم ومحرك الألعاب (يعمل بدون إنترنت عدا الخط)
